# `smart-header`

**Catégorie :** Navigation

## Intention
L'en-tête se cache quand on descend dans la page et réapparaît dès qu'on remonte.

## Ce qu'on ressent
Discret, il laisse de la place au contenu sans se perdre.

## Utilisation
```html
<header data-fx="smart-header">…</header>
```

## Paramètres
- Fonctionne dans la page ou dans une boîte qui défile
- Classe `fx-scrolled` ajoutée dès qu'on a défilé (ombre)

## Quand l'utiliser
En-têtes de sites de contenu, d'articles, d'applications.

## Quand l'éviter
Les en-têtes qui contiennent une action indispensable en permanence.

## Accessibilité
L'en-tête réapparaît dès qu'un de ses éléments reçoit le focus clavier.
