# `ribbon-sine`

**Catégorie :** Ambiance

## Intention
Un ruban formé de dizaines de lignes fines ondule comme un tissu dans le vent.

## Ce qu'on ressent
Soie, fluidité, élégance scientifique.

## Utilisation
```html
<section data-fx="ribbon-sine">…</section>
```

## Paramètres
- `data-fx-lines` (34) : nombre de lignes
- `--fx-line` : couleur

## Quand l'utiliser
En-têtes de page, sections d'introduction.

## Quand l'éviter
Les interfaces très denses.

## Accessibilité
Avec `prefers-reduced-motion: reduce`, le ruban reste immobile.
