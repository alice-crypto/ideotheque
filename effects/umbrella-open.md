# `umbrella-open`

**Catégorie :** Entrée

## Intention
Un parapluie s'ouvre d'un ressort et les gouttes de pluie s'écartent de lui.

## Ce qu'on ressent
Protection simple et un peu de tendresse.

## Utilisation
```html
<div data-fx="umbrella-open"></div>
```

## Paramètres
- `--fx-s` (150px), `--fx-rain`
- `data-fx-label` : description si l'image a un sens

## Quand l'utiliser
Assurance, météo, hero de marque rassurante.

## Quand l'éviter
Une image déjà vue partout si la marque veut se distinguer.

## Accessibilité
Décoratif par défaut. Avec le mouvement réduit, le parapluie apparaît ouvert par la bibliothèque.
