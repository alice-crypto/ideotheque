# `ink-spread`

**Catégorie :** Entrée

## Intention
Le contenu se répand depuis le coin bas gauche, comme une goutte d'encre sur du papier.

## Ce qu'on ressent
Organique, doux, artistique.

## Utilisation
```html
<div data-fx="ink-spread">…</div>
```

## Paramètres
- `--fx-duration` (700ms), `--fx-delay` (0ms) — durée réelle 1,6 fois plus longue

## Quand l'utiliser
Visuels d'ambiance, cartes colorées, sections artistiques.

## Quand l'éviter
Les interfaces denses : l'animation est lente.

## Accessibilité
Avec `prefers-reduced-motion: reduce`, l'effet est désactivé et le contenu s'affiche directement.
