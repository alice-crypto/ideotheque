# `letter-focus`

**Catégorie :** Texte

## Intention
Chaque lettre sort du flou à un instant aléatoire, comme une image qui se précise.

## Ce qu'on ressent
Mystérieux, onirique, raffiné.

## Utilisation
```html
<h2 data-fx="letter-focus">Apparition</h2>
```

## Paramètres
- `--fx-duration` (700ms), `--fx-delay` (0ms) — les lettres se répartissent sur 0,7 s

## Quand l'utiliser
Titres d'ambiance, citations, noms de marque.

## Quand l'éviter
Les textes à lire vite.

## Accessibilité
Le texte d'origine reste lisible par les lecteurs d'écran via `aria-label`.
