# `node-bloom`

**Catégorie :** Entrée

## Intention
Une petite constellation se forme : un noyau, des liens qui se tracent, des points qui éclosent, puis une orbite très lente.

## Ce qu'on ressent
Des idées qui se relient d'elles-mêmes.

## Utilisation
```html
<span data-fx="node-bloom" data-fx-nodes="4"></span>
```

## Paramètres
- `data-fx-nodes` (3), `data-fx-seed` (0) : composition
- `--fx-size` (96px), `--fx-accent`

## Quand l'utiliser
Les icônes d'une liste de services ou d'étapes.

## Quand l'éviter
Plus de six par écran : les orbites se disputent l'attention.

## Accessibilité
Décoratif (`aria-hidden`). Mouvement réduit : la constellation est déjà formée et immobile.
