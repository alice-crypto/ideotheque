# `holo-card`

**Catégorie :** Présentation

## Intention
Une carte holographique : des reflets irisés et une lueur suivent le curseur pendant qu'elle s'incline.

## Ce qu'on ressent
Précieux, collection, carte rare.

## Utilisation
```html
<div data-fx="holo-card">…</div>
```

## Paramètres
Aucun paramètre : les couleurs du reflet sont dans le CSS du pack.

## Quand l'utiliser
Cartes de membre, badges, objets numériques, offres premium.

## Quand l'éviter
Les cartes contenant beaucoup de texte (les reflets gênent la lecture).

## Accessibilité
Avec `prefers-reduced-motion: reduce`, la carte ne s'incline pas ; les reflets suivent toujours le curseur.
