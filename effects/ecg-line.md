# `ecg-line`

**Catégorie :** Ambiance

## Intention
Un tracé cardiaque défile en effaçant devant lui, au rythme choisi.

## Ce qu'on ressent
Vivant, clinique, précis.

## Utilisation
```html
<div data-fx="ecg-line" data-fx-bpm="72"></div>
```

## Paramètres
- `data-fx-bpm` (72), `data-fx-speed` (70) : pixels par seconde
- `--fx-h`, `--fx-line`, `data-fx-label`

## Quand l'utiliser
Cardiologie, objets connectés, hero santé.

## Quand l'éviter
De faire passer ce tracé pour une mesure réelle : il est généré.

## Accessibilité
Rôle `img` avec une description. Avec le mouvement réduit, le tracé reste fixe.
