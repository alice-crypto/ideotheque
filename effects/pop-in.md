# `pop-in`

**Catégorie :** Entrée

## Intention
L'élément surgit de 55 % à sa taille, la dépasse légèrement puis se stabilise.

## Ce qu'on ressent
Joyeux, rebondi, très « application ».

## Utilisation
```html
<button data-fx="pop-in">…</button>
```

## Paramètres
- `--fx-duration` (700ms), `--fx-delay` (0ms)

## Quand l'utiliser
Pastilles, avatars, notifications, boutons d'action.

## Quand l'éviter
Les grands blocs : le dépassement paraît brutal.

## Accessibilité
Avec `prefers-reduced-motion: reduce`, l'effet est désactivé et le contenu s'affiche directement.
