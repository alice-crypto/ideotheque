# `film-sheen`

**Catégorie :** Texte

## Intention
Un reflet de nacre qui tourne vers le curseur, sur un texte ou sur la bordure d'une carte.

## Ce qu'on ressent
Une couleur qui n'existe pas : elle change quand on bouge.

## Utilisation
```html
<em data-fx="film-sheen">lumière</em>
```

## Paramètres
- `data-fx-on="border"` : sur la bordure seulement
- `--fx-film-colors` : les couleurs du reflet
- `--fx-radius` (20px)

## Quand l'utiliser
Un mot d'accent, une carte qu'on veut distinguer.

## Quand l'éviter
Un fond clair avec le texte : ces couleurs pâles y perdent leur contraste.

## Accessibilité
Réservez-le aux fonds où le contraste reste suffisant. Mouvement réduit : reflet fixe.
