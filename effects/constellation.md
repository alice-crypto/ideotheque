# `constellation`

**Catégorie :** Ambiance

## Intention
Des points dérivent et se relient par des lignes quand ils sont proches ; le curseur se relie aussi à eux.

## Ce qu'on ressent
Réseau, connexion, intelligence.

## Utilisation
```html
<section data-fx="constellation">…</section>
```

## Paramètres
- `data-fx-count` (46) : nombre de points
- `data-fx-link` (110) : distance de liaison
- `--fx-line`, `--fx-node` : couleurs

## Quand l'utiliser
Sites de réseaux, d'IA, de données, d'entreprises tech.

## Quand l'éviter
Les mobiles peu puissants avec beaucoup de points.

## Accessibilité
Avec `prefers-reduced-motion: reduce`, une seule image fixe est dessinée. Le canvas est masqué aux lecteurs d'écran.
