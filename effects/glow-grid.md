# `glow-grid`

**Catégorie :** Ambiance

## Intention
Une grille fine, estompée sur les bords, dont les lignes s'allument autour du curseur.

## Ce qu'on ressent
Technique, précis, « plan de travail » de produit numérique.

## Utilisation
```html
<section data-fx="glow-grid">…</section>
```

## Paramètres
- `--fx-cell` (56px) : taille des cases
- `--fx-grid-line` : couleur des lignes au repos
- `--fx-accent` : couleur des lignes allumées
- `--fx-glow` (220px) : rayon de la lueur

## Quand l'utiliser
Héros de produits tech, sections « fonctionnalités », fonds clairs comme sombres.

## Quand l'éviter
Les sections déjà chargées en motifs ; les écrans tactiles n'ont pas la lueur.

## Accessibilité
Purement décoratif, sans effet sur le contenu.
