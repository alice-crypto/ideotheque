# `scan-reveal`

**Catégorie :** Image

## Intention
L'image apparaît par fines lignes horizontales qui s'épaississent jusqu'à se toucher.

## Ce qu'on ressent
Vieux téléviseur, fax, image transmise de loin.

## Utilisation
```html
<img data-fx="scan-reveal" src="photo.jpg" alt="…">
```

## Paramètres
- `data-fx-gap` (10) : écart entre les lignes
- `data-fx-duration` (1100) : durée en millisecondes

## Quand l'utiliser
Portfolios, archives, sites techniques.

## Quand l'éviter
Les petites images, où les lignes ne se distinguent pas.

## Accessibilité
Avec `prefers-reduced-motion: reduce`, l'image s'affiche complète.
