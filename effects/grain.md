# `grain`

**Catégorie :** Ambiance

## Intention
Un grain de pellicule animé recouvre le contenu, comme un film argentique.

## Ce qu'on ressent
Analogique, texturé, cinéma d'auteur.

## Utilisation
```html
<section data-fx="grain">…</section>
```

## Paramètres
- `--fx-grain` (0.14) : intensité du grain

## Quand l'utiliser
Sections photo, héros éditoriaux, fonds unis trop lisses.

## Quand l'éviter
Les textes fins sur fond clair : le grain les rend moins nets.

## Accessibilité
Avec `prefers-reduced-motion: reduce`, l'animation est figée.
