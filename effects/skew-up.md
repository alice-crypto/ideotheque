# `skew-up`

**Catégorie :** Entrée

## Intention
Le contenu monte en se redressant d'une légère inclinaison.

## Ce qu'on ressent
Vif, élégant, très typographique.

## Utilisation
```html
<h2 data-fx="skew-up">…</h2>
```

## Paramètres
- `--fx-duration` (700ms), `--fx-delay` (0ms)
- `--fx-distance` (24px, multiplié par 1,6)

## Quand l'utiliser
Grands titres, citations, accroches.

## Quand l'éviter
Les images avec des lignes droites (architecture) : l'inclinaison se voit trop.

## Accessibilité
Avec `prefers-reduced-motion: reduce`, l'effet est désactivé et le contenu s'affiche directement.
