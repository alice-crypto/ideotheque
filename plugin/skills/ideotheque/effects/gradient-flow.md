# `gradient-flow`

**Catégorie :** Texte

## Intention
Un dégradé de couleurs coule en continu à l'intérieur des lettres.

## Ce qu'on ressent
Vivant, lumineux, moderne.

## Utilisation
```html
<h1>Créez <span data-fx="gradient-flow">librement</span></h1>
```

## Paramètres
- `--fx-accent`, `--fx-accent-2` : couleurs du dégradé

## Quand l'utiliser
Un mot clé dans un titre, un logo texte.

## Quand l'éviter
Les textes longs : l'œil est attiré partout à la fois.

## Accessibilité
Avec `prefers-reduced-motion: reduce`, l'effet est désactivé et le contenu s'affiche directement.
