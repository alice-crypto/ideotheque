# `number-stack-in`

**Catégorie :** Entrée

## Intention
Plusieurs copies en contour d'un grand numéro se rassemblent et forment le numéro final.

## Ce qu'on ressent
Écho, impression en plusieurs passages.

## Utilisation
```html
<div data-fx="number-stack-in">03</div>
```

## Paramètres
Aucun réglage.

## Quand l'utiliser
Numéros de chapitre, dates, chiffres clés.

## Quand l'éviter
Les petits numéros.

## Accessibilité
Le numéro est dans `aria-label`, les copies sont masquées.
