# `word-rise`

**Catégorie :** Texte

## Intention
Les mots montent un par un depuis la ligne de base.

## Ce qu'on ressent
Posé, rythmé comme une phrase prononcée.

## Utilisation
```html
<h2 data-fx="word-rise">Des idées qui bougent</h2>
```

## Paramètres
- `--fx-duration` (700ms), `--fx-delay` (0ms)
- `--fx-stagger` (70ms) : décalage entre deux mots

## Quand l'utiliser
Titres, slogans, phrases d'introduction.

## Quand l'éviter
Les paragraphes longs : plus de 25 mots, la fin arrive trop tard.

## Accessibilité
Le texte d'origine reste lisible par les lecteurs d'écran via `aria-label`.
