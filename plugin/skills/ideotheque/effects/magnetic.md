# `magnetic`

**Catégorie :** Micro-interaction

## Intention
Un bouton attiré par le curseur, qui invite au clic.

## Ce qu'on ressent
Joueur, tactile, haut de gamme.

## Utilisation
```html
<button data-fx="magnetic" data-fx-strength="0.35">Commencer</button>
```

## Paramètres
- `data-fx-strength` (0.35) : force de l'attraction, de 0 à 1

## Quand l'utiliser
Le bouton d'action principal, une seule fois par écran.

## Quand l'éviter
Les interfaces denses ou les formulaires (déplacer une cible gêne le clic).

## Accessibilité
Avec `prefers-reduced-motion: reduce`, l'effet est désactivé et le contenu s'affiche directement.
