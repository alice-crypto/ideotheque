# `orbit-rings`

**Catégorie :** Ambiance

## Intention
Trois anneaux pointillés tournent autour du centre, chacun portant une petite planète.

## Ce qu'on ressent
Cosmique, systémique, calme.

## Utilisation
```html
<div data-fx="orbit-rings"><img src="logo.svg" alt="…"></div>
```

## Paramètres
- `--fx-ring` : couleur des anneaux, `--fx-planet` : couleur des planètes

## Quand l'utiliser
Logos au centre, schémas d'écosystème, écrans de chargement.

## Quand l'éviter
Les éléments très étroits : les anneaux sont coupés.

## Accessibilité
Avec `prefers-reduced-motion: reduce`, l'animation est figée.
