# `wave-text`

**Catégorie :** Texte

## Intention
Une vague parcourt les lettres en boucle, de gauche à droite.

## Ce qu'on ressent
Ludique, musical, détendu.

## Utilisation
```html
<span data-fx="wave-text">Vague</span>
```

## Paramètres
Aucun paramètre : la vague dure 1,8 s et se décale de 90 ms par lettre.

## Quand l'utiliser
Mots courts : « Chargement », un logo, un appel joyeux.

## Quand l'éviter
Les textes à lire attentivement et les interfaces sérieuses.

## Accessibilité
Le texte d'origine reste lisible par les lecteurs d'écran via `aria-label`. Avec `prefers-reduced-motion: reduce`, les lettres restent immobiles.
