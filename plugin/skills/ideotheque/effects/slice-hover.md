# `slice-hover`

**Catégorie :** Texte

## Intention
Au survol, le texte se coupe horizontalement en deux moitiés qui glissent en sens opposés.

## Ce qu'on ressent
Tranchant, éditorial, inattendu.

## Utilisation
```html
<a href="…" data-fx="slice-hover">Contact</a>
```

## Paramètres
- `--fx-slice-color` : couleur du texte

## Quand l'utiliser
Liens de navigation en gros caractères, noms de projets.

## Quand l'éviter
Les textes sur plusieurs lignes : l'effet ne fonctionne que sur une ligne.

## Accessibilité
Le texte réel reste dans le document (rendu transparent) : il est lu normalement.
