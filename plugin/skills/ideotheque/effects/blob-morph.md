# `blob-morph`

**Catégorie :** Micro-interaction

## Intention
La forme ondule comme une goutte d'eau tant qu'on la survole.

## Ce qu'on ressent
Organique, doux, vivant.

## Utilisation
```html
<button data-fx="blob-morph">Go</button>
```

## Paramètres
Aucun paramètre.

## Quand l'utiliser
Boutons ronds, avatars, pastilles décoratives.

## Quand l'éviter
Les boutons avec beaucoup de texte : la déformation gêne la lecture.

## Accessibilité
Les effets de survol se déclenchent aussi au focus clavier quand c'est possible. Avec `prefers-reduced-motion: reduce`, les transitions sont instantanées.
