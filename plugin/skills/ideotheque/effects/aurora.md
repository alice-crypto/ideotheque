# `aurora`

**Catégorie :** Ambiance

## Intention
Des voiles de couleur floue ondulent lentement derrière le contenu, comme une aurore boréale.

## Ce qu'on ressent
Apaisant, lumineux, futuriste.

## Utilisation
```html
<section data-fx="aurora">…</section>
```

## Paramètres
- `--fx-a1`, `--fx-a2`, `--fx-a3` : les trois couleurs

## Quand l'utiliser
Héros de page, sections d'appel à l'action, cartes premium.

## Quand l'éviter
Derrière des textes longs : le contraste varie en permanence.

## Accessibilité
Avec `prefers-reduced-motion: reduce`, l'animation est figée.
