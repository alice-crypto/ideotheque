# `glitch-text`

**Catégorie :** Texte

## Intention
Le texte se dédouble en rouge et cyan par à-coups, comme un signal numérique perturbé. Plus fréquent au survol.

## Ce qu'on ressent
Numérique, nerveux, cyberpunk.

## Utilisation
```html
<h1 data-fx="glitch-text">SIGNAL</h1>
```

## Paramètres
Les couleurs (#ff2e63, #08d9d6) se changent dans le CSS du pack.

## Quand l'utiliser
Titres d'univers jeu vidéo, techno, événements musicaux.

## Quand l'éviter
Les textes longs et les publics sensibles aux effets clignotants.

## Accessibilité
Avec `prefers-reduced-motion: reduce`, le dédoublement est coupé.
