# `gradient-drift`

**Catégorie :** Ambiance

## Intention
Un dégradé maillé de quatre couleurs dérive lentement en fond.

## Ce qu'on ressent
Doux, vivant, très « produit numérique ».

## Utilisation
```html
<section data-fx="gradient-drift">…</section>
```

## Paramètres
- `--fx-d1` à `--fx-d4` : couleurs, `--fx-base` : fond

## Quand l'utiliser
Fonds de héros, cartes, écrans d'accueil.

## Quand l'éviter
Les pages déjà très colorées.

## Accessibilité
Avec `prefers-reduced-motion: reduce`, l'animation est figée.
