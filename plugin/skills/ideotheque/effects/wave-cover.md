# `wave-cover`

**Catégorie :** Transition

## Intention
Une vague liquide monte du bas, recouvre l'écran, puis s'en va vers le haut.

## Ce qu'on ressent
Marée, souplesse, un geste liquide.

## Utilisation
```html
<a href="/menu" data-fx="wave-cover">Menu</a>
```

## Paramètres
- `--fx-tr-color` : couleur

## Quand l'utiliser
Marques de boisson, de bien-être, sites joyeux.

## Quand l'éviter
Les interfaces de travail.

## Accessibilité
Avec `prefers-reduced-motion: reduce`, le changement de page se fait sans transition.
