# `jelly`

**Catégorie :** Micro-interaction

## Intention
L'élément tremble comme une gelée au survol avant de se stabiliser.

## Ce qu'on ressent
Cartoon, ludique, plein d'énergie.

## Utilisation
```html
<button data-fx="jelly">Boing</button>
```

## Paramètres
Aucun paramètre.

## Quand l'utiliser
Boutons de jeu, mascottes, icônes.

## Quand l'éviter
Les interfaces professionnelles.

## Accessibilité
Les effets de survol se déclenchent aussi au focus clavier quand c'est possible. Avec `prefers-reduced-motion: reduce`, les transitions sont instantanées.
