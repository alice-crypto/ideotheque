# `versus-bars`

**Catégorie :** Présentation

## Intention
Deux valeurs se font face : les barres partent de chaque bord et se rencontrent à la frontière.

## Ce qu'on ressent
Duel, match, avant et après.

## Utilisation
```html
<div data-fx="versus-bars" data-fx-a="62" data-fx-b="38"></div>
```

## Paramètres
- `data-fx-a`, `data-fx-b` : valeurs
- `data-fx-name-a`, `data-fx-name-b` : noms
- `--fx-a-c`, `--fx-b-c` : couleurs

## Quand l'utiliser
Comparaison de deux options, résultats, gains.

## Quand l'éviter
Plus de deux valeurs.

## Accessibilité
Les valeurs sont écrites en texte à côté des barres.
