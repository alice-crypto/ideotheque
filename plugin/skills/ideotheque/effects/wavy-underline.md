# `wavy-underline`

**Catégorie :** Texte

## Intention
Un soulignement ondulé qui se met à filer quand on le survole.

## Ce qu'on ressent
Joueur, manuscrit, sympathique.

## Utilisation
```html
<a href="…" data-fx="wavy-underline">en savoir plus</a>
```

## Paramètres
- `--fx-wave-color` (accent) : couleur de l'onde

## Quand l'utiliser
Liens dans un texte décontracté, mots mis en avant.

## Quand l'éviter
Les liens d'une interface sobre.

## Accessibilité
Avec `prefers-reduced-motion: reduce`, l'effet est désactivé et le contenu s'affiche directement.
