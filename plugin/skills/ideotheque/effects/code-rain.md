# `code-rain`

**Catégorie :** Ambiance

## Intention
Des colonnes de signes tombent en traînées lumineuses, comme une pluie de code.

## Ce qu'on ressent
Hacker, numérique, mystérieux.

## Utilisation
```html
<section data-fx="code-rain">…</section>
```

## Paramètres
- `data-fx-size` (14) : taille des signes
- `--fx-rain` (#20c7a5) : couleur

## Quand l'utiliser
Sites de cybersécurité, de jeux, écrans d'attente.

## Quand l'éviter
Les publics sensibles aux scintillements.

## Accessibilité
Avec `prefers-reduced-motion: reduce`, une seule image fixe est dessinée. Le canvas est masqué aux lecteurs d'écran.
