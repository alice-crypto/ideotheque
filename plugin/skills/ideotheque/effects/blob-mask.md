# `blob-mask`

**Catégorie :** Image

## Intention
L'image est découpée dans une forme molle qui ondule en continu.

## Ce qu'on ressent
Organique, doux, original.

## Utilisation
```html
<img data-fx="blob-mask" src="…" alt="…">
```

## Paramètres
Aucun paramètre.

## Quand l'utiliser
Portraits, avatars, illustrations de section.

## Quand l'éviter
Les images dont les bords contiennent l'information.

## Accessibilité
Avec `prefers-reduced-motion: reduce`, la forme reste fixe.
