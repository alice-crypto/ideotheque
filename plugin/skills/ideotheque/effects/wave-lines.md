# `wave-lines`

**Catégorie :** Ambiance

## Intention
Des lignes ondulantes se superposent et se déplacent comme des ondes sonores.

## Ce qu'on ressent
Fluide, musical, élégant.

## Utilisation
```html
<section data-fx="wave-lines">…</section>
```

## Paramètres
- `data-fx-lines` (14) : nombre de lignes
- `data-fx-speed` (0.6) : vitesse
- `--fx-w1`, `--fx-w2` : couleurs

## Quand l'utiliser
Héros de sites audio, fonds de section, pieds de page.

## Quand l'éviter
Derrière du texte dense.

## Accessibilité
Avec `prefers-reduced-motion: reduce`, une seule image fixe est dessinée. Le canvas est masqué aux lecteurs d'écran.
