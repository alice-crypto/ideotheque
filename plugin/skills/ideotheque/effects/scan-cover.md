# `scan-cover`

**Catégorie :** Transition

## Intention
Un rayon lumineux traverse l'écran de haut en bas et laisse un aplat derrière lui.

## Ce qu'on ressent
Scanner, analyse, technologie.

## Utilisation
```html
<a href="/analyse" data-fx="scan-cover">Analyse</a>
```

## Paramètres
- `--fx-tr-color` : couleur de l'aplat
- `--fx-accent` : couleur du rayon

## Quand l'utiliser
Produits techniques, IA, sécurité.

## Quand l'éviter
Les ambiances chaleureuses.

## Accessibilité
Avec `prefers-reduced-motion: reduce`, le changement de page se fait sans transition.
