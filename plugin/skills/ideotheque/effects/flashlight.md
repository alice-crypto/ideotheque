# `flashlight`

**Catégorie :** Ambiance

## Intention
L'obscurité recouvre l'élément et seul le cercle éclairé par le curseur laisse voir le contenu.

## Ce qu'on ressent
Mystère, exploration, jeu.

## Utilisation
```html
<section data-fx="flashlight">…</section>
```

## Paramètres
- `--fx-size` (120px) : rayon de la lampe
- `--fx-dark-veil` : couleur de l'obscurité

## Quand l'utiliser
Pages de découverte, jeux, révélations.

## Quand l'éviter
Les contenus importants : sur mobile, il n'y a pas de curseur pour éclairer.

## Accessibilité
Le contenu reste dans le document : il est lu normalement par les lecteurs d'écran. Prévoyez une alternative sur écran tactile.
