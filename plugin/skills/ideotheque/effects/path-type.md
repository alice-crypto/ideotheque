# `path-type`

**Catégorie :** Texte

## Intention
Le texte suit une ligne ondulée et y avance en continu, comme un ruban.

## Ce qu'on ressent
Fluide, organique, une enseigne qui ondule.

## Utilisation
```html
<div data-fx="path-type">Livraison offerte</div>
```

## Paramètres
- `data-fx-path` : tracé SVG personnalisé
- `data-fx-speed` (2.4) : vitesse
- `--fx-size` (34px) : taille du texte, à l'échelle du dessin

## Quand l'utiliser
Séparateurs de sections, accroches décoratives.

## Quand l'éviter
Une information indispensable : le texte n'est jamais lu d'un seul regard.

## Accessibilité
Le texte est dans `aria-label`, le dessin est masqué aux lecteurs d'écran.
