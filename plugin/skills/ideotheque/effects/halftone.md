# `halftone`

**Catégorie :** Ambiance

## Intention
Une trame de points d'imprimerie apparaît en tache qui se déplace lentement.

## Ce qu'on ressent
Imprimé, pop art, bande dessinée.

## Utilisation
```html
<section data-fx="halftone">…</section>
```

## Paramètres
- `--fx-dot` (accent) : couleur des points

## Quand l'utiliser
Fonds de section, cartes, illustrations.

## Quand l'éviter
Derrière du texte de petite taille.

## Accessibilité
Avec `prefers-reduced-motion: reduce`, l'animation est figée.
