# `flip-up`

**Catégorie :** Entrée

## Intention
L'élément bascule vers l'avant depuis sa base, comme une carte qu'on relève sur une table.

## Ce qu'on ressent
Physique, en trois dimensions, ludique.

## Utilisation
```html
<article data-fx="flip-up">…</article>
```

## Paramètres
- `--fx-duration` (700ms), `--fx-delay` (0ms)

## Quand l'utiliser
Cartes, tuiles de fonctionnalités, résultats.

## Quand l'éviter
Les très grands blocs : la perspective les déforme fortement.

## Accessibilité
Avec `prefers-reduced-motion: reduce`, l'effet est désactivé et le contenu s'affiche directement.
