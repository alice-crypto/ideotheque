# `char-flip`

**Catégorie :** Texte

## Intention
Chaque lettre bascule en 3D depuis le haut pour se mettre en place.

## Ce qu'on ressent
Mécanique, comme un panneau qu'on retourne.

## Utilisation
```html
<h2 data-fx="char-flip">Bascule</h2>
```

## Paramètres
- `--fx-duration` (700ms), `--fx-delay` (0ms) — décalage de 40 ms par lettre

## Quand l'utiliser
Titres courts, chiffres, noms.

## Quand l'éviter
Les phrases longues.

## Accessibilité
Le texte d'origine reste lisible par les lecteurs d'écran via `aria-label`.
