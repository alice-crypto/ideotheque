# `skew-scroll`

**Catégorie :** Défilement

## Intention
Le contenu penche légèrement selon la vitesse du défilement, puis se redresse.

## Ce qu'on ressent
Inertie, matière souple, énergie.

## Utilisation
```html
<section data-fx="skew-scroll">…</section>
```

## Paramètres
Aucun paramètre (inclinaison maximale 10°).

## Quand l'utiliser
Grilles d'images, titres, sections visuelles.

## Quand l'éviter
Les longs textes.

## Accessibilité
Avec `prefers-reduced-motion: reduce`, l'élément reste dans son état final, sans suivre le défilement.
