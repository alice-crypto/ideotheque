// Manifeste

Avant, on partageait des bibliothèques de style. Avec l'IA, on partage des idées : un nom, une intention, un ressenti que n'importe quel assistant sait reproduire.

Le catalogue

Cliquez, survolez, rejouez.

Aucun effet ne correspond.

Trois étapes.

01 — Inclure

Deux fichiers.

Aucune dépendance, aucun framework imposé.

<link rel="stylesheet" href="fx.css">
<script src="fx.js" defer></script>
02 — Nommer

Un attribut.

Le nom de l'effet suffit. Réglages via des variables CSS.

<img data-fx="pixel-dissolve"
     data-fx-cols="16" src="…">
03 — Demander

Ou laissez l'IA faire.

Utilise line-mask pour les titres et page-wipe entre les pages.
Fait. J'ai suivi les fiches effects/line-mask.md et effects/page-wipe.md, réduit le mouvement si l'utilisateur le demande.
